# Apex Rush

Мобильная гоночная игра на Three.js: Koenigsegg Gemera, Porsche 911 GT3 R, Ferrari Daytona SP3; трассы Drift Park и Motegi Twin Ring.

## Выложить на GitHub Pages
1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки (index.html, .nojekyll, assets/).
   Если файлов много для веб-загрузки, используй GitHub Desktop или `git push`.
2. Settings, затем Pages, затем Source: Deploy from a branch, ветка main, папка / (root).
3. Через минуту игра откроется на https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/

## Как это устроено
- assets/std: стандартные модели (быстро, для любого телефона).
- assets/hd: HD-модели (в 2-3 раза больше полигонов, текстуры до 2К). Включаются пресетом «Ультра» или переключателем в настройках.
- Модели грузятся только выбранной машины и трассы, остальные по нажатию на карточку. Скачанное кэшируется в браузере, повторный вход быстрый.
- Размер: std около 11 МБ, hd около 20 МБ. Ограничения GitHub (файл до 100 МБ, сайт до 1 ГБ) не превышены.
